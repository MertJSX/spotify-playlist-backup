# Spotify playlist backup
It periodically creates backups for your 'Liked songs' playlist. It contains one txt file and one json file. It only holds artist and music name nothing else. I created it for my personal needs and if you also need something like this. You can use it freely.

## How to set it up
- Create your Spotify application from *developer.spotify.com*. Then make sure to add Redirect URI. 'localhost' keyword will not work, it didn't worked on me use '127.0.0.1' instead.
- Change config.yml and after installing the dependencies just start the program.
